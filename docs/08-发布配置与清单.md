## 二、Android 发布（在装有 Android SDK 的机器上）

```bash
# 1) 生成正式 keystore（仅一次，密码离线保存）
keytool -genkeypair -v \
  -keystore ../keystore/reading-tracker-release.keystore \
  -keyalg RSA -keysize 2048 -validity 10000 -alias readingtracker

# 2) 填写 android/key.properties（参考 key.properties.example）

# 3) 安装编译依赖（compileSdk 36 需要对应 Android SDK Platform 36）
#    Android Studio / sdkmanager 中安装 "Android SDK Platform 36" 与 "Build-Tools"

# 4) 取依赖并生成 i18n 代码
flutter pub get
flutter gen-l10n

# 5) 构建 AAB（Google Play 只收 AAB，不收 APK）
flutter build appbundle --release

# 产物：build/app/outputs/bundle/release/app-release.aab
```

- **包名（applicationId / Bundle Identifier）**：已定稿为 `io.github.ltong9463.readnest`（产品名 **Readnest**，**上架后不可更改**）。Android 在 `build.gradle` 的 `namespace`/`applicationId`、iOS 在 `project.pbxproj` 的 `PRODUCT_BUNDLE_IDENTIFIER` 均已改好。注意：Dart 内部包名仍为 `reading_tracker`（`pubspec.yaml` 的 `name`），因 24 个 test/tool 文件用 `package:reading_tracker/...` 导入，改名会批量破坏，故保留——它不暴露给用户。
- **应用图标**：仍为 Flutter 默认模板图。正式图标由开发者本人设计，**规格与安全区数值见 `store/assets/icon-spec.md`**；把母版放到 `store/assets/icon-master.png` 后跑 `bash scripts/store-assets.sh`，19 个 iOS 档位 + Android legacy/自适应全套 + Play 商店 512 图标一次性派生。**`android:icon` 无需改动**，API 26+ 会自动优先匹配 `mipmap-anydpi-v26/`。
- **混淆（P3-4）**：在 `build.gradle` release 块中开启 `minifyEnabled` / `shrinkResources` 并补 `proguard-rules.pro`（ML Kit 需 keep 规则）后再发布。

## 三、iOS 发布（两条路径，任选）

### 路径 A：自有 Mac + Xcode（本地）
```bash
# 现有 ios/ 已是标准模板，且已补好 Podfile / Info.plist 用途声明 / 隐私清单，
# 无需再 flutter create（否则会覆盖我们手改的 Info.plist）。
flutter pub get
flutter gen-l10n
cd ios && pod install && cd ..
# Xcode 中：Signing 选 Team、Bundle Identifier 定稿、部署目标 15.5
flutter build ios --release
# 或 Xcode → Product → Archive → Distribute App
```

### 路径 B：Codemagic 云构建（无需自备 Mac）
> 开发者明确表示「iOS 环境我不懂」，推荐走这条路。已提供 `codemagic.yaml`：
> 关联仓库即云端 macOS 出 IPA，签名在 Codemagic 控制台配置。
> 脚本会在 `flutter create --platforms=ios .` 之后用 PlistBuddy 重新注入
> 相机/相册用途描述与多语言声明、补回隐私清单，避免生成步骤覆盖合规信息。
```bash
# 本地无需任何操作；在 https://codemagic.io 关联仓库，选择 ios-release workflow。
# 控制台上传 Apple 分发证书 + App Store 描述文件（或开启 Automatic code signing）。
```

### 隐私清单现状（`ios/Runner/PrivacyInfo.xcprivacy`）

这份文件曾经有**三处会直接拦下上传**的错误，已修正：

| 原值 | 问题 | 现为 |
|---|---|---|
| `NSPrivacyCollectedDataTypeUserContent` | 不是合法键名 | `NSPrivacyCollectedDataTypeOtherUserContent` |
| `NSPrivacyAccessedAPICategoryFileManager` | 不在五个合法分类内（会报 **ITMS-91055**） | `NSPrivacyAccessedAPICategoryFileTimestamp` |
| 理由码 `0D5T.1` | 不在该分类的允许清单内（同上 **ITMS-91055**） | `C617.1`（仅作用于本应用容器内） |
| `NSPrivacyAppBuiltInBrowserSupport` | 不是清单键 | 已删除 |

当前声明：`NSPrivacyTracking = false`；数据类型 2 项（`PhotosorVideos`、`OtherUserContent`，均不关联身份、用途 AppFunctionality）；required-reason API 2 项（`UserDefaults` → `CA92.1`，`FileTimestamp` → `C617.1`）。

> ⚠️ 键名大小写是逐字符敏感的：`PhotosorVideos` 中间是小写 `or`，写成 `PhotosOrVideos` 同样会被判非法。
> 归档时以 Xcode 的 **Product → Archive → Generate Privacy Report** 汇总结果为准（它会合并 App 与全部第三方 SDK 各自的清单）。
> **待决**：ML Kit 会回传性能/使用指标，按 Google 服务条款开发者有告知义务。是否补一条 `Diagnostics → Performance Data` 声明见 `docs/09` 第五节。

## 四、商店后台必填

| 平台 | 必填项 | 用哪个文件 |
|---|---|---|
| Google Play | 应用名称 / 简短说明 / 完整说明 | `store/listing/google-play.{zh,en}.md` |
| Google Play | 应用图标 512×512（≤1 MB，允许 alpha） | `store/assets/icon-play-512.png` |
| Google Play | **应用特色图片 1024×500（必交）** | `store/assets/feature-graphic.{zh,en}.png` |
| Google Play | 手机截图 2–8 张 | `store/screenshots/play/{zh,en}/01…06-*.png`（1080×1920） |
| Google Play | 数据安全表单 | `store/privacy/google-play-data-safety.md`（逐项答案） |
| Google Play | 隐私政策网址 | `https://kjlintong.github.io/privacy.html`（中）/ `privacy-en.html`（英） |
| App Store | 名称 / 副标题 / 促销文本 / 关键词 / 描述 | `store/listing/app-store.{zh,en}.md` |
| App Store | App 图标 1024×1024（**无 alpha**） | `app/ios/Runner/Assets.xcassets/AppIcon.appiconset/Icon-App-1024x1024@1x.png` |
| App Store | iPhone **6.9 寸**截图（必交） | `store/screenshots/iphone69/{zh,en}/…`（1320×2868） |
| App Store | iPad **13 寸**截图（`TARGETED_DEVICE_FAMILY="1,2"`，**必交**） | `store/screenshots/ipad13/{zh,en}/…`（2064×2752） |
| App Store | App 隐私标签 + 隐私清单 | `store/privacy/app-store-app-privacy.md` + `PrivacyInfo.xcprivacy` |
| 两者 | 内容分级 | 无账号、无 UGC、无广告 → 通常 4+ / 「所有人」 |
| 两者 | 应用内购买 | **无**（免费，打赏走站外 Ko-fi，不接 IAP） |

> ⚠️ **不要拿 `app/test/goldens/` 那 14 张图当上架素材**：它们是 1170×2532，
> 长边 / 短边 = 2.16，而 Google Play 明文规定长边不得超过短边的 2 倍，会被直接拒收。
> 两批图用途不同：goldens 做视觉回归，`store/screenshots/` 才是商店素材。
