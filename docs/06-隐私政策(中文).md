## 一、我们的数据定位

本应用采用 **本地优先（local-first）** 架构：

- 您的书架、阅读进度、笔记、统计与设置 **全部存储于您设备本地的数据库（SQLite）**；
- 我们 **不提供任何账号体系，也没有后端服务器收集或存储您的数据**；
- 我们 **不会出售、出租或共享您的个人数据给任何第三方用于广告或营销**。

---

## 二、我们处理哪些数据

- **本地存储的数据**：您主动添加或导入的书籍信息（书名、作者、分类、进度、评分、笔记、封面等）、阅读统计与应用设置。这些数据仅存在于您的设备。
- **您主动填写的密钥**：若您使用「微信读书同步」或「大模型」功能，需在设置中填写相应的 API Key / Base URL / 模型名。这些凭据 **仅保存在您设备的系统密钥库（Android Keystore / iOS Keychain，通过 flutter_secure_storage 实现）中**，**不会以明文形式落在应用的 SQLite 数据库里**；它们不会上传给我们，也只会随您的请求发往您自己指定的服务端点。
- **我们不收集**：本应用未集成任何第三方统计分析、广告或崩溃上报 SDK，不会采集设备标识符、精确位置或您的使用行为。仅有一处例外：拍照导入所用的**端侧文字识别 SDK（Google ML Kit）**会向 Google 发送**与图片内容无关的匿名运行指标**，详见第三节第 4 条。

## 三、数据会在什么情况下离开您的设备

本应用仅在您 **主动启用并配置相应功能** 时，才会与第三方服务通信。所有通信均经由您自行提供的凭证，指向您自己选择的服务端点。

### 1. 微信读书同步（可选）
- **触发条件**：您在设置中填写了微信读书 API Key。
- **发送对象**：腾讯微信读书官方网关 `https://i.weread.qq.com`。
- **发送内容**：用于拉取您书架、阅读进度、阅读统计与书城搜索的 API 请求。
- **说明**：该服务由腾讯运营，服务器位于中国境内。若您不填写该 Key，本应用不会与该服务通信。

### 2. 大模型 / AI 功能（可选）
您可在设置中填写任意兼容 OpenAI 或 Anthropic 协议的 LLM 端点（含 Base URL、API Key、模型名）。以下数据会在您触发对应功能时发送到您填写的端点：
- **元数据补全**：为缺信息的书籍补全分类 / 简介 / 标签时，发送书名、作者等少量信息。
- **阅读报告生成**：生成定期阅读报告时，发送 **聚合后的阅读统计**，以及报告周期内 **变化过的书籍的书名、作者、分类、阅读状态与评分**（**不含笔记正文**）。
- **截图识别（多模态）**：当您开启"用大模型整理识别结果"或"多模态直接读图"导入书架截图 / 照片时，**您所选的那张图片（JPEG）会被上传到您配置的多模态模型端点**，用于识别书名。该功能为可选项，且每次导入都需要您主动选择图片并确认。

> **重要同意**：截图可能包含您书架上的书名、封面等个人信息。上传图片到多模态模型属于敏感数据处理，本应用在使用该功能前会 **请求您的单独明示同意**，您可随时在设置中关闭。

### 3. 公开元数据服务（可选）
为补全书籍封面、简介、ISBN 等信息，本应用会向以下公开 API 发起按"书名 / 作者"的查询：
- Google Books API（`https://www.googleapis.com/books/v1/volumes`）
- Open Library（`https://openlibrary.org`）

这些查询仅包含您正在导入书籍的标题 / 作者，用于匹配公开书目数据；在无法直连的网络环境下会自动跳过，不会中断导入。

此外，当书籍带有封面时，应用会从封面图片的存放地址（通常是 `books.google.com` 或 `covers.openlibrary.org`）**直接下载图片用于界面显示**。该请求只包含图片地址本身，不含您的任何信息。

### 4. 端侧文字识别 SDK 的运行指标（自动）

拍照 / 相册导入中的文字识别由 **Google ML Kit** 在您的设备本地完成，**被识别的图片及其识别结果不会离开您的设备**。但根据 Google 官方的 ML Kit 服务条款，该 SDK 会：

- 不定时连接 Google 服务器，用于获取缺陷修复、更新的识别模型与硬件加速兼容性信息；
- 向 Google 发送**该 SDK 在本应用中的性能与使用指标**（例如接口调用次数、处理耗时、设备机型与系统版本）。

这些指标描述的是 SDK 自身的运行状况，**不包含被识别的图片、您的书名或笔记内容**；我们（开发者）也接收不到这些指标。该行为由 SDK 决定，应用无法关闭。若您完全不使用拍照 / 相册导入，也就不会产生这些请求。

条款来源：https://developers.google.com/ml-kit/terms
